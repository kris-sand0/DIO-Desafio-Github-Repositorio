# DIO — Desafio GitHub: Meu Primeiro Repositório

Este repositório foi criado como parte do desafio da [Digital Innovation One (DIO)](https://www.dio.me/) para praticar o uso do Git e do GitHub e compartilhar meu progresso nos estudos.

## 🎯 Objetivo

Aprender os fundamentos de controle de versão e utilizar o GitHub para organizar, documentar e compartilhar meus estudos.

## 📚 O que pratiquei

- Criação e clonagem de um repositório
- Criação e atualização de arquivos Markdown
- Verificação de alterações com `git status`
- Preparação de arquivos com `git add`
- Registro de alterações com `git commit`
- Envio e sincronização com `git push` e `git pull`
- Consulta do histórico com `git log`
- Criação e troca de branches
- Incorporação de alterações com `git merge`

## 🧰 Comandos Git

| Comando | Para que serve |
|---|---|
| `git clone <url>` | Clona um repositório remoto |
| `git status` | Mostra o estado dos arquivos |
| `git add .` | Prepara as alterações para commit |
| `git commit -m "mensagem"` | Registra as alterações |
| `git push` | Envia commits para o GitHub |
| `git pull` | Atualiza a cópia local com alterações remotas |
| `git log --oneline` | Exibe o histórico resumido |
| `git switch -c <branch>` | Cria e muda para uma branch |
| `git merge <branch>` | Incorpora uma branch à branch atual |
