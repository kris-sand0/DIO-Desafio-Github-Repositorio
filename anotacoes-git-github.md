# Minhas Anotações — Git e GitHub

## O que é Git?

Git é um sistema de controle de versão.
Ele permite acompanhar as alterações feitas
nos arquivos de um projeto.

## O que é GitHub?

GitHub é uma plataforma online que permite
armazenar repositórios Git e compartilhar
projetos com outras pessoas.

## Comandos básicos

### Verificar o estado do repositório

git status

### Adicionar arquivos para registro

git add .

### Registrar uma alteração

git commit -m "Minha primeira alteração"

### Enviar alterações para o GitHub

git push

## Meu aprendizado

Hoje aprendi a clonar um repositório do
GitHub para o meu computador e verificar
se ele está sincronizado.

## Segundo aprendizado

Aprendi que o Git permite registrar
o histórico de alterações de um projeto.

Cada commit representa um registro
de uma alteração realizada.

## Terceiro aprendizado

Aprendi que o git pull permite
atualizar meu repositório local
com as alterações do GitHub.

## Trabalhando com branches

Uma branch permite desenvolver
alterações separadamente da branch principal.
